## 🔴 高风险问题

### 1. 路径遍历漏洞 (Path Traversal)

**文件**: `frontend/index.html`  
**行号**: ~第 280 行附近 (`loadImage` 函数)

```javascript
function loadImage(filename) {
    const img = new Image();
    img.src = 'assets/' + filename;  // ⚠️ 未验证 filename
    return img;
}
```

**风险分析**：
- `filename` 参数直接拼接到路径中，攻击者可通过构造 `../../../etc/passwd` 或 `..%2F..%2F` 等 payload 访问服务器敏感文件
- 虽然这是客户端代码，但若 `assets/` 目录托管于服务器，可能被利用

**建议修复**：
```javascript
function loadImage(filename) {
    // 白名单验证：只允许字母、数字、下划线、点、连字符
    if (!/^[a-zA-Z0-9_.\-]+$/.test(filename)) {
        console.error('Invalid filename:', filename);
        return null;
    }
    const img = new Image();
    img.src = 'assets/' + filename;
    return img;
}
```

## 🟡 中等风险问题

### 2. 内存泄漏风险 - 对象无限累积

**文件**: `frontend/index.html`

```javascript
let gameState = {
    // ...
    floatingTexts: [],  // ⚠️ 无上限累积
    particles: []       // ⚠️ 无上限累积
};
```

**问题描述**：
- `floatingTexts` 和 `particles` 数组持续增长，从不清理
- 每帧生成浮动文字和粒子动画，会导致内存持续增长
- 在移动设备或长时间运行后可能引发卡顿或崩溃

**建议修复**：
```javascript
// 添加对象池和自动清理机制
const MAX_PARTICLES = 500;
const MAX_FLOATING_TEXTS = 100;

// 在游戏循环中添加清理逻辑
function cleanup() {
    gameState.particles = gameState.particles.filter(p => p.life > 0);
    gameState.floatingTexts = gameState.floatingTexts.filter(t => t.life > 0);
    
    if (gameState.particles.length > MAX_PARTICLES) {
        gameState.particles = gameState.particles.slice(-MAX_PARTICLES);
    }
    if (gameState.floatingTexts.length > MAX_FLOATING_TEXTS) {
        gameState.floatingTexts = gameState.floatingTexts.slice(-MAX_FLOATING_TEXTS);
    }
}
```

### 4. 缺少错误处理机制

**文件**: `frontend/index.html`

```javascript
// 示例：多个地方缺少 try-catch
function loadImage(filename) {
    const img = new Image();
    img.src = 'assets/' + filename;  // 无错误处理
    // 没有 onerror 回调
    return img;
}

ctx.drawImage(...)  // Canvas 操作无错误处理
JSON.parse(...)     // JSON 解析无保护
```

**风险**：图片加载失败或数据解析错误会导致游戏崩溃，用户无法得知原因

**建议修复**：
```javascript
function loadImage(filename, onLoad, onError) {
    const img = new Image();
    img.onload = () => onLoad && onLoad(img);
    img.onerror = () => {
        console.error(`Failed to load image: ${filename}`);
        onError && onError(filename);
    };
    img.src = 'assets/' + filename;
    return img;
}

// 安全 JSON 解析
function safeJSONParse(str, defaultValue = null) {
    try {
        return JSON.parse(str);
    } catch (e) {
        console.error('JSON parse error:', e);
        return defaultValue;
    }
}
```
